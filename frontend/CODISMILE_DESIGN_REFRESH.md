# CodiSmile Design Refresh

The landing page was redesigned using the CodiSmile promotional images supplied with the project request.

## Supplied assets
- `public/codismile/hero.jpg` — clinic hero/treatment room reference
- `public/codismile/location.jpg` — clinic location/map graphic
- `public/codismile/crowns.jpg` — crown education graphic
- `public/codismile/crowns-info.jpg` — crown/esthetic education graphic
- `public/codismile/whitening.jpg` — whitening education graphic
- `public/codismile/signs-cover.jpg` — oral-health signs cover
- `public/codismile/signs-1-2.jpg`, `signs-3-4.jpg`, `signs-5.jpg` — signs education graphics
- `public/codismile/logo.jpg` — cropped CodiSmile logo reference

The graphics are user-supplied clinic materials. Replace them only with clinic-approved assets if the clinic provides higher-resolution originals.

## Dashboard interactions
- Search opens from the top-right search icon and queries authorized patients through the existing API.
- Notifications open from the bell icon and summarize current high-risk cases, today's screenings, and the next upcoming appointment using existing API data.
- Notification/search items navigate to the relevant existing ToothWise pages.
