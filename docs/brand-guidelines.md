# CodiSmile Dental Clinic / ToothWise Brand Guidelines

## Brand
- Brand: CodiSmile Dental Clinic
- Product: ToothWise
- Category: Dental clinic patient portal + AI-assisted screening workflow
- Voice: calm, reassuring, clear, professional, practical, privacy-conscious
- Avoid: hype, exaggerated medical claims, fake testimonials, unexplained AI language

## Logo
- Source of truth: `frontend/public/codismile/codismile-logo-transparent.png`
- Also retained: `frontend/public/codismile/codismile-clinic-logo.jpg` as supplied fallback.
- Use the full-color logo on light backgrounds whenever possible.
- Never stretch, rotate, recolor, gradient-fill, crop, or add a shadow to the logo.
- Keep clear space around the logo. Recommended clear space: at least the mark height.
- Minimum digital width for the full logo: 120px; icon-only minimum: 24px.

## UI Direction
- Quiet editorial healthcare interface.
- Generous whitespace and strong alignment.
- Soft surfaces, thin borders, restrained shadows.
- Use Lucide SVG icons, never emoji as interface icons.
- Rounded corners are functional, generally 12–20px.
- Primary CTAs use solid CodiSmile plum for legible contrast rather than a light rose fill.
- Motion is purposeful, short for controls, and always honors reduced motion.
